# Test case: v0007.33-state-registry-admin-jwt-fails-closed

## Implements

`state-registry` — `### Requirement: State Registry authenticates team administrators without local accounts`

## Intent

Provider-neutral authentication E2E test verifying State Registry validates the complete admin JWT trust contract and fails closed on signing-key outages.

## Preconditions

- Admin JWT fixtures can vary issuer, audience, algorithm, signature, `kid`, `iat`, `exp`, age, role pointer, and role shape.
- Admin JWKS supports cached-key success, rotation, unavailable response, and timeout.
- State Registry request and database observations are available.

## Steps

1. Call team create, update, and archive with each invalid claim, signature, age, and exact-role variant.
2. Validate a cached known key, rotate to a new known key, and retry successfully.
3. Present unknown `kid` while JWKS is unavailable and while it exceeds `admin_jwks_timeout`.
4. Assert response-specific error envelopes and exact absence of team reads or writes on every rejected request.

## Expected outcome

Invalid authentication returns `401 invalid_admin_token`; valid authentication without the exact role returns `403 insufficient_admin_role`. Cached and rotated valid keys work. Unknown `kid` plus JWKS outage or timeout returns `502 admin_identity_provider_unavailable`, never accepts an unrelated cached key, and performs no team read or mutation.
