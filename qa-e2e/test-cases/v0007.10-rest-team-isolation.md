# Test case: v0007.10-rest-team-isolation

## Implements

`api-gateway` — `### Requirement: State Registry remains authoritative for resource ownership`

## Intent

Security test verifying REST isolation by stable token `team_id` while State Registry remains the ownership authority.

## Preconditions

- Valid operator tokens exist for `team-alpha` and `team-beta`.
- State Registry holds one task for each team; both teams may share the same display name.

## Steps

1. Request the `team-alpha` task using the `team-alpha` token.
2. Request the `team-beta` task using the `team-alpha` token.
3. Request the `team-beta` task using the `team-beta` token.

## Expected outcome

State Registry returns only same-`team_id` resources, denies the cross-team request regardless of display-name equality, and the Gateway forwards each success or denial unchanged.
