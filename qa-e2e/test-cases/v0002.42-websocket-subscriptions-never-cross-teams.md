# Test case: v0002.42-websocket-subscriptions-never-cross-teams

## Implements

`state-registry` — `### Requirement: State Registry isolates WebSocket subscriptions by team`.

## Intent

Verify concurrent replay and live subscriptions bind immutable team context at upgrade and never emit a cross-team signal.

## Preconditions

Trusted Gateway contexts for `team-a` and `team-b` can upgrade WebSockets; both teams have replayable events and can generate live events with identical kinds and filters.

## Steps

1. Open concurrent subscriptions for both teams with identical filters and cursors.
2. Generate replayable and live task, Executor, control, environment, secret, and audit activity in both teams.
3. On the `team-a` connection, request a filter naming a real `team-b` identifier.
4. Capture frames, cursor movement, counts, and connection behavior for both subscriptions.

## Expected outcome

Each connection receives only frames for its immutable bound `team_id`; replay selection, filters, cursors, fan-out, and serialization exclude foreign rows before shaping. The foreign identifier produces no frame, count, cursor, error distinction, or existence signal.
