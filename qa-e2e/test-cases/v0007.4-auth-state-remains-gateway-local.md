# Test case: v0007.4-auth-state-remains-gateway-local

## Implements

`auth` — `### Requirement: Auth remains gateway-local`

## Intent

Boundary test verifying that State Registry is neither an auth/session store nor a recipient of browser credentials or Gateway auth-audit records.

## Preconditions

- Gateway auth auditing is enabled to a test auth log.
- State Registry records child headers and platform writes.

## Steps

1. Log in and perform one authenticated State Registry read through the Gateway.
2. Inspect State Registry headers and persisted platform writes.
3. Inspect the separate Gateway auth log.

## Expected outcome

State Registry receives trusted identity context but no bearer/session credential, contains no auth-session or Gateway auth-audit platform record, and the separate Gateway auth log contains the authentication audit entry.
