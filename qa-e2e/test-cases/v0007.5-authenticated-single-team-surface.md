## Implements

`web-ui` — `### Requirement: Web UI renders one selected-team operator surface`

## Intent

Happy-path test verifying the UI displays resolved teams and permits only resolved-team selection.

## Preconditions

- OIDC teams resolve through API Gateway's database to State Registry-owned `team-alpha` / `Alpha Team` and `team-beta` / `Beta Team`.

## Steps

1. Sign in through the Web UI.
2. Inspect the displayed team list and select `team-beta`.
3. Inspect visible team administration and membership controls.

## Expected outcome

The dashboard displays both canonical team IDs and names, permits selection only from the resolved list, obtains a one-team `team-beta` working token, and provides no team CRUD or membership-management control.
