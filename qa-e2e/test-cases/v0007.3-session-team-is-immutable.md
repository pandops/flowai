# Test case: v0007.3-session-team-is-immutable

## Implements

`auth` — `### Requirement: Each working token has one immutable active team`

## Intent

Security test verifying that refresh and browser input cannot switch the active team within a session.

## Preconditions

- Operator working token is bound to `team-alpha`, while fresh OIDC team resolution also permits `team-beta`.
- The OIDC team granting `team-alpha` can be removed during the test.

## Steps

1. Request refresh of the `team-alpha` token while supplying `team-beta`.
2. Remove the OIDC team mapped to `team-alpha`.
3. Attempt another refresh of the original token.

## Expected outcome

The Gateway never returns a refreshed token that changes the original immutable `team-alpha` claim. The explicit switch requires a separately issued token after fresh resolution, and refresh after membership removal is rejected.
