# Test case: v0006.2-gateway-only-browser-backend

## Implements

`web-ui` — `### Requirement: Configured adapter is the only browser backend`

## Intent

Verify that all browser traffic uses the test-only mocked proxy.

## Preconditions

- Web UI, mocked proxy, State Registry, and Executor recorder origins are distinct.

## Steps

1. Exercise reads, a mutation, cancellation, and live subscription.
2. Inspect all browser HTTP and WebSocket destinations.

## Expected outcome

Every browser backend request targets the mocked proxy. No browser request
targets State Registry or an Executor, and no production API Gateway process
is started or required.

## Implementation reference

`qa-e2e/web-ui/tests/v0006-selected-team.spec.ts` — `v0006.2 browser uses only the configured mocked proxy origin`.
