# Test case: v0002.50-team-default-image-resolves-when-task-image-absent

## Implements

`state-registry` — `### Requirement: State Registry requires a default image at team registration`.

`state-registry` — `### Requirement: State Registry resolves the effective image at claim by four-level precedence`.

## Intent

Verify that when a `pending` task has no `image` override and neither `task_types.default_image` nor `source_systems.default_image` applies, the Registry persists `tasks.resolved_image` equal to the team's `default_image` (always present by registration) and returns `resolved_image` with `image_source = team_default` in the claim response.

## Preconditions

- An authenticated system administrator has created `team-a` through `POST /admin/teams` with the required opaque `default_image = default-A`; no listener, Executor, or Gateway path can change or clear it.
- A `team-a` listener is authorized for `team-a` and one registered source system.
- A `team-a` Executor is registered with `team-a` and one authorized tag.
- `team-a` has a registered task type `tt-a1` with `execution_tag = openhands`.
- A `team-a` `pending` task exists with `image` unset on the task, REQUIRED non-null `task_type_id = tt-a1`, and `task_types.default_image` null.

## Steps

1. Read `team-a` and confirm `default_image = default-A` is present and non-null.
2. From the same-team Executor, submit `POST /v1/executors/{executor_id}/claim` with the oldest eligible pending `task_id` and a fresh `command_id`.
3. Inspect the `200 claimed` response and capture `resolved_image` and `image_source`.
4. Read the canonical task back through trusted Gateway context and confirm `resolved_image = default-A`, `image_source = team_default`, `tasks.executor_id` non-null, `tasks.owner_command_id` non-null, `tasks.claimed_at` set, and `current_state = created` with one event in history.
5. Restart the State Registry and re-read the task through trusted Gateway context; confirm `resolved_image`, `tasks.executor_id`, `tasks.owner_command_id`, and the history are unchanged.

## Expected outcome

The claim response contains `resolved_image = default-A` and `image_source = team_default`. The canonical task's `resolved_image` is persisted equal to `default-A`. The FIRST `created` event is Registry-appended at claim time with non-null `executor_id` identifying the claiming Executor. After restart, all persisted fields are the same value. The team default is required and immutable through any operator or admin path; corrections require a new team. Image equality across teams grants no authority. Audit entries for the `default_image` write are plaintext-free.
