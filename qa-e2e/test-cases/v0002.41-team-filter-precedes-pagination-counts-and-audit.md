# Test case: v0002.41-team-filter-precedes-pagination-counts-and-audit

## Implements

`state-registry` — `### Requirement: State Registry filters team-scoped reads before result shaping`.

`state-registry` — `### Requirement: State Registry records plaintext-free team audit entries`.

## Intent

Verify team predicates precede pages, cursors, totals, counts, aggregates, serialization, and audit reads.

## Preconditions

`team-a` and `team-b` have tasks, Executors, events, controls, environments, secrets, versions, and audits sharing the same filter values; foreign rows would alter global page boundaries and counts.

## Steps

1. Query each supported collection as trusted Gateway context for `team-a` with small page limits and shared filters.
2. Follow every returned cursor and request totals, counts, groupings, and aggregates where supported.
3. Record the responses, remove only `team-b` fixtures, and repeat identical `team-a` queries.
4. Inspect authorized audit payloads for plaintext.

## Expected outcome

Before and after removing foreign fixtures, `team-a` rows, page lengths, cursor sequence, totals, counts, groupings, aggregates, empty/non-empty distinctions, and serialized results are identical. Audit entries contain team, actor, action, resource, request, outcome, and timestamp without plaintext values.
