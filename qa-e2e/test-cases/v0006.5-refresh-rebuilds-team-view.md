# Test case: v0006.5-refresh-rebuilds-team-view

## Implements

`web-ui` — `### Requirement: Client state is non-authoritative`

## Intent

Verify refresh and team switching rebuild views from the adapter rather than stale client state.

## Preconditions

- Both supplied teams contain distinguishable canonical tasks.

## Steps

1. Select `team-beta`, open its task, then change canonical state through test setup.
2. Refresh and switch to `team-alpha` while delaying an old beta response.

## Expected outcome

Refresh shows current beta state; selection shows only alpha state; the delayed
beta response is ignored and no canonical state is persisted in the browser.

## Implementation reference

`qa-e2e/web-ui/tests/v0006-selected-team.spec.ts` — `v0006.5 refresh rebuilds the selected-team view from the adapter`.

RED: `npx playwright test tests/v0006-selected-team.spec.ts --timeout=10000` — selected-team UI was absent. GREEN: `npx playwright test` — passed.
