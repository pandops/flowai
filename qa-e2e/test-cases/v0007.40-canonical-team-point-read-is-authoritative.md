# Test case: v0007.40-canonical-team-point-read-is-authoritative

## Implements

`state-registry` — ``### Requirement: State Registry owns team registration through `/admin/teams` ``

`api-gateway` — `### Requirement: Gateway owns OIDC-to-canonical-team mappings`

## Intent

Contract and authorization E2E test verifying Gateway and system administrators can read current canonical team presentation without gaining a collection scan or leaking membership data.

## Preconditions

- State Registry owns distinguishable active, archived, and missing team IDs.
- A valid system-admin token, credential-free Gateway backend client, operator working token, and invalid admin tokens are available.
- Gateway mapping registration and `GET /auth/v1/teams` use the production State Registry client.

## Steps

1. Call admin-only `GET /admin/teams/{team_id}` for active and archived teams with the system-admin identity and call internal `GET /internal/v1/teams/{team_id}` through Gateway's credential-free backend client.
2. Rename and archive a mapped team, then call `GET /auth/v1/teams` and register a mapping to another archived team.
3. Call the point read with malformed, expired, or insufficient-role admin bearers and a missing `team_id`.
4. Attempt collection-style `GET /admin/teams` and vary State Registry outage and timeout during Gateway mapping and team-list operations.
5. Inspect response fields, Gateway outbound identity, and absence of OIDC/operator membership data.

## Expected outcome

Authorized admin and credential-free Gateway backend point reads return exactly current `team_id`, `team_name`, `default_image`, `ingested_at`, and nullable `archived_at` for active and archived teams. Gateway refreshes renamed/archive presentation and validates mappings through this contract without a replacement service credential. Invalid admin bearers return `401` or `403`, missing team returns `404 canonical_team_not_found`, and no collection GET exists. Gateway converts dependency outage/timeout to `503 state_registry_unavailable` without stale presentation or partial mapping persistence.
