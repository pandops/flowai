# Test case: v0006.1-configured-team-operator-surface

## Implements

`web-ui` — `### Requirement: Web UI renders one selected-team operator surface`

## Intent

Verify that the UI always has one active team and can switch between externally supplied teams.

## Preconditions

- Mocked proxy supplies `team-alpha` and `team-beta`; it performs no Keycloak or membership lookup.

## Steps

1. Open the dashboard and record the initially selected team and requests.
2. Select the other team using the visible selector.
3. Visit dashboard, tasks, Executors, launch parameters, and audit.

## Expected outcome

Exactly one team is selected at a time. After selection, every later REST path
and live subscription uses the new `team_id`; stale first-team responses do
not render. No team CRUD, membership, Keycloak, source-system, task-type, or
global-admin control is present.

## Implementation reference

`qa-e2e/web-ui/tests/v0006-selected-team.spec.ts` — `v0006.1 selects one supplied team and replaces context on switch`.
