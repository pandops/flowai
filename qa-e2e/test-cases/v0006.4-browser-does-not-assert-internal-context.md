# Test case: v0006.4-browser-does-not-assert-internal-context

## Implements

`web-ui` — `### Requirement: Web UI does not assert authentication context`

## Intent

Verify that the browser sends the selected team as ordinary API data without fabricating authentication context.

## Preconditions

- Browser request inspection is enabled.

## Steps

1. Trigger REST and WebSocket operations after selecting a team.
2. Inspect URLs, bodies, and headers.

## Expected outcome

The selected `team_id` appears only in the documented path or subscription
field. No bearer token, operator identity, Keycloak group, membership proof,
or trusted internal context header is generated by v0006.

## Implementation reference

`qa-e2e/web-ui/tests/v0006-selected-team.spec.ts` — `v0006.4 sends selected team as API data without auth context`.

RED: `npx playwright test tests/v0006-selected-team.spec.ts --timeout=10000` — selected-team request path was absent. GREEN: `npx playwright test` — passed.
