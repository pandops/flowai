# Test case: v0007.26-websocket-auth-lifecycle

## Implements

`auth` — `### Requirement: Gateway validates operator and team claims`

## Intent

Security and lifecycle test verifying WebSocket upgrade authentication, expiry closure, and team-isolated reconnect behavior.

## Preconditions

- Test working tokens cover missing, invalid signature, expired, short-lived valid, and renewed valid variants for `team-alpha`.
- State Registry can publish distinguishable replay and live events for `team-alpha` and `team-beta` and record subscription attempts.
- The Gateway contract defines WebSocket application close code `4401` with reason `working_token_expired`.

## Steps

1. Attempt upgrades without a token and with invalid or expired tokens.
2. Open a connection with the short-lived valid token and forged internal context headers.
3. Publish same-team and foreign-team events before token expiry.
4. Wait for token `exp`, observe closure, and attempt reconnect with the expired token.
5. Issue a new same-team token, reconnect, and observe replay plus live events.

## Expected outcome

Invalid upgrades return `401` and create no State Registry subscription. The valid connection uses only canonical context, exposes only `team-alpha` frames, and closes at `exp` with code `4401` and reason `working_token_expired`. Reconnect with the expired token returns `401`; reconnect with the new token succeeds and exposes only `team-alpha` replay and live frames. No browser bearer reaches State Registry.

## Implementation reference

- Production: `svc/api-gateway/internal/httpapi/server.go` (`proxyWebSocket`) and `svc/api-gateway/internal/workingtoken/verifier.go`.
- E2E: `qa-e2e/api-gateway/tests/v0007-authenticated-websocket.spec.ts` — `v0007.15 v0007.26 authenticate, isolate, expire, and renew WebSockets`.
- RED evidence: the exact command first failed because the replay frame raced listener attachment, then failed because an expired token was accepted inside verification skew and rejected later as inaccessible; both defects were corrected.
- GREEN evidence: `npm --prefix qa-e2e/api-gateway test -- tests/v0007-authenticated-websocket.spec.ts` — 1 passed on 2026-08-27.
