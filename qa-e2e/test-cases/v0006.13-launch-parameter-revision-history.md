# Test case: v0006.13-launch-parameter-revision-history

## Implements

`state-registry` — `### Requirement: State Registry stores immutable launch-parameter revisions`.

`web-ui` — `### Requirement: Web UI renders launch-parameter revision history`.

## Intent

Happy-path and isolation coverage verifying that ordinary env history is
derived from immutable launch-parameter revisions without exposing secrets.

## Preconditions

- `team-alpha` and `team-beta` each own launch parameters.
- The `team-alpha` definition contains ordinary env values and one logical
  secret reference.
- Mocked proxy integration mode forwards the browser-selected `team-alpha`.

## Steps

1. Replace the `team-alpha` definition with one ordinary env value changed.
2. Open that variable's «История изменений» in the Web UI.
3. Delete the definition and read its history again.
4. Request the `team-beta` revision collection under the selected
   `team-alpha` UI path through the same mocked proxy.

## Expected outcome

Replace and delete append consecutive immutable revisions, including a final
tombstone; the Web UI derives the env-key history from those revisions;
responses contain no secret plaintext or cryptographic material; and the
foreign history request returns the same non-revealing `404` as unknown
without count or cursor leakage.
