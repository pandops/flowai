# Test case: v0007.15-authenticated-websocket-team-isolation

## Implements

`api-gateway` — `### Requirement: Gateway establishes trusted canonical-team context`

## Intent

Security test verifying canonical team context, spoof resistance, bearer containment, and cross-team isolation on authenticated WebSockets.

## Preconditions

- A valid token identifies `operator-1` and `team-alpha`.
- State Registry can publish distinguishable events for `team-alpha` and `team-beta` and capture subscription headers.

## Steps

1. Open a WebSocket with the valid token and forged internal headers identifying `operator-2` and `team-beta`.
2. Publish one `team-alpha` event and one `team-beta` event.
3. Observe the State Registry subscription context and browser event frames.

## Expected outcome

State Registry receives canonical `operator-1`, `team-alpha`, optional display-only canonical team name, and a Gateway-generated request ID with no forged values or browser bearer; the browser receives only the `team-alpha` event frame.

## Implementation reference

- Production: `svc/api-gateway/internal/httpapi/server.go` (`proxyWebSocket`, `authenticateWorkingToken`, `websocketBearer`).
- E2E: `qa-e2e/api-gateway/tests/v0007-authenticated-websocket.spec.ts` — `v0007.15 v0007.26 authenticate, isolate, expire, and renew WebSockets`.
- GREEN evidence: `npm --prefix qa-e2e/api-gateway test -- tests/v0007-authenticated-websocket.spec.ts` — 1 passed on 2026-08-27.
