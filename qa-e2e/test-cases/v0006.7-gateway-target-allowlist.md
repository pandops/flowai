# Test case: v0006.7-gateway-target-allowlist

## Implements

`mocked-proxy` — `### Requirement: Mocked proxy excludes administration and ingestion`

## Intent

Verify that browser-visible proxy routes exclude administration, ingestion, Executors, and arbitrary targets.

## Preconditions

- Backend recorders observe attempted forwarding.

## Steps

1. Use a supported UI route, then attempt admin, ingestion, Executor, and arbitrary targets.

## Expected outcome

Only the supported UI adapter route is forwarded. Every excluded target is
rejected before a backend call.

## Implementation reference

`qa-e2e/web-ui/tests/v0006-mocked-proxy-rest.spec.ts` — `v0006.7 forwards only allowlisted UI adapter routes`. RED exposed unrestricted forwarding; GREEN is included in the 24/24 Web UI suite.
