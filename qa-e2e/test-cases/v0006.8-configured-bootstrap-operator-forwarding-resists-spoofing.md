# Test case: v0006.8-configured-bootstrap-operator-forwarding-resists-spoofing

## Implements

`mocked-proxy` — `### Requirement: Mocked proxy forwards the selected team identifier`

## Intent

Verify that the proxy forwards the browser-selected team rather than a configured first team.

## Preconditions

- Team list order is alpha then beta; forwarding capture is enabled.

## Steps

1. Select beta and perform reads and writes across all team-scoped pages.

## Expected outcome

Every forwarded path contains beta and none contains alpha. The proxy does not
add operator, authentication, Keycloak, or membership context.

## Implementation reference

`qa-e2e/web-ui/tests/v0006-mocked-proxy-rest.spec.ts` — `v0006.8 preserves the selected team id and adds no identity headers`. GREEN is included in the 24/24 Web UI suite; mocked proxy strips browser identity headers and forwards only the selected path `team_id`.
