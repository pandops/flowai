# Test case: v0006.30-dashboard-counts-new-task-live

## Implements

`web-ui` — `### Requirement: Web UI renders an actionable task dashboard`.

## Intent

Verify that ingestion of a new same-team task updates an already open
dashboard exactly once and without a manual reload.

## Preconditions

- State Registry, Web UI, and the mocked proxy are running for the captured
  test team.
- State Registry and browser clocks use a controlled current-day boundary.
- The dashboard is open with period «День» and its baseline total, all five
  status counts, and chart buckets are captured.
- The test team's task type uses an execution tag for which no Executor is
  currently eligible, so the new task remains `pending` long enough for a
  deterministic assertion.
- The mocked proxy forwards real committed State Registry changes and records
  monotonic receipt time; it does not alter dashboard counters itself.

## Steps

1. Through the listener API, ingest one uniquely identified same-team task
   inside the current day and require `201 Created`; capture its `task_id` and
   State Registry commit time.
2. Keep the dashboard open without navigation, reload, polling the page from
   the test, or modifying mocked-proxy fixture data.
3. Wait for the live update and record when the browser renders the changed
   counters and chart.
4. Compare the visible total, each lifecycle-status count, and the applicable
   chart bucket with the captured baseline.
5. Replay the last committed live frame once, then reconnect from the last
   committed cursor and inspect the dashboard again.
6. Commit an otherwise equivalent task for a foreign team and observe the
   configured-team dashboard.

## Expected outcome

Within two seconds of the mocked proxy receiving the committed same-team
frame, the visible total, `pending` count, and current-day chart bucket each
increase by exactly one; `created`, `running`, `finished`, and `failed` remain
unchanged. The update occurs without page reload and is announced to assistive
technology without moving keyboard focus. Replay and cursor reconnect do not
increment any value again. The foreign-team commit changes no visible count,
series, request scope, or accessible announcement.
