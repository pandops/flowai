# Test case: v0006.16-dashboard-status-drilldown

## Implements

`web-ui` — `### Requirement: Web UI renders an actionable task dashboard`.

## Intent

Verify navigable ISO-week and calendar-month selection, complete zero-filled
calendar buckets, subdued chart styling, and browser-history restoration.

## Preconditions

- A mocked proxy serves the current Web UI HTTP and WebSocket contract for `team-alpha`; no API Gateway process is required.
- The configured team has sparse task activity in the current and earlier ISO
  weeks and calendar months, including days with no tasks.

## Steps

1. Open the dashboard and verify the current `Week NN, YYYY` selection, seven
   ordered Monday-through-Sunday bars, and the absence of a day selector and
   dashboard status cards.
2. Verify zero-task days, including future days in the current week, remain
   present and visually distinguishable from a day containing one task.
3. Navigate to the previous week and verify the selected ISO week is reflected
   in the URL; use browser Back and Forward and verify the visible calendar is
   restored.
4. Switch to month and verify every day of the selected calendar month appears,
   including days without tasks.
5. Navigate to an earlier month and verify future navigation is unavailable
   from the current month.
6. Activate a non-empty daily bucket and verify task history opens with the
   bucket's exact `date=YYYY-MM-DD` in the URL, visible Date filter, and proxy
   request; verify the matching task is visible.

## Expected outcome

The dashboard exposes only week and month calendars; week always contains
seven ordered days and month contains every day in that month. Empty and future
days remain visible with zero totals, a positive value is visually distinct
from zero, bars use a subdued non-primary color, calendar navigation updates
URL state, and Back/Forward restores the selected period.
Activating a daily bucket opens history filtered to that exact UTC date.

`qa-e2e/web-ui/tests/v0006-mission-control.spec.ts` — `v0006.16 dashboard uses navigable complete calendar periods and subdued chart`.
