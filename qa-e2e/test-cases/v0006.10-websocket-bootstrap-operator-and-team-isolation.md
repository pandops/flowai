# Test case: v0006.10-websocket-bootstrap-operator-and-team-isolation

## Implements

`mocked-proxy` — `### Requirement: Mocked proxy forwards the selected team identifier`

## Intent

Verify live subscription replacement when the UI changes teams.

## Preconditions

- Both teams emit distinguishable live frames.

## Steps

1. Subscribe while alpha is selected, then switch to beta.
2. Publish frames for both teams and observe upstream subscriptions and UI.

## Expected outcome

The alpha subscription closes, a beta subscription opens, and after switching
only beta frames render; late alpha frames are ignored.

## Implementation reference

`qa-e2e/web-ui/tests/v0006-selected-team-websocket.spec.ts` —
`v0006.10 replaces the selected-team live subscription and ignores late frames`.

RED: `npx playwright test tests/v0006-selected-team-websocket.spec.ts --timeout=10000`
— timed out because the UI opened no team stream. GREEN:
`npx tsc --noEmit && npx playwright test tests/v0006-selected-team-websocket.spec.ts`
— passed.
