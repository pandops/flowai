# Test case: v0006.9-state-registry-enforces-resource-ownership-and-audit

## Implements

`state-registry` — `### Requirement: State Registry exposes the v0006 UI API surface`

## Intent

Verify selected-team path scoping and non-revealing cross-team resource handling.

## Preconditions

- Alpha and beta own distinct resources with one deliberately reused display name.

## Steps

1. Request beta's resource under alpha's team path.
2. Mutate an alpha resource and inspect its audit entry.

## Expected outcome

The cross-team lookup returns the documented non-revealing not-found response;
the valid mutation affects and audits only alpha. Display names never scope data.
