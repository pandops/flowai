# Test case: v0007.8-no-auth-mode-is-disabled

## Implements

`api-gateway` — `### Requirement: Gateway requires authenticated proxy mode`

## Intent

Failure-path test verifying that protected REST and WebSocket traffic can no longer use v0006 no-auth bootstrap behavior.

## Preconditions

- v0007 auth mode is enabled.
- State Registry records child requests and subscriptions.

## Steps

1. Send a protected REST request without a bearer token.
2. Attempt a protected WebSocket upgrade without a bearer token.
3. Inspect State Registry observations.

## Expected outcome

The Gateway rejects both operations before proxying, and State Registry receives no REST request or WebSocket subscription.

## Implementation reference

- REST: `qa-e2e/api-gateway/tests/v0007-authenticated-rest.spec.ts` — `v0007.8 missing bearer is rejected before State Registry`.
- WebSocket: `qa-e2e/api-gateway/tests/v0007-authenticated-websocket.spec.ts` — missing-token upgrade assertion.
- Production: `svc/api-gateway/internal/httpapi/server.go` (`authenticateWorkingToken`).
