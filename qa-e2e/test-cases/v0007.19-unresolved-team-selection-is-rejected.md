# Test case: v0007.19-unresolved-team-selection-is-rejected

## Implements

`api-gateway` — `### Requirement: Gateway owns OIDC-to-canonical-team mappings`

## Intent

Security test verifying that Gateway issues a working token only for a team in its fresh membership resolution.

## Preconditions

- OIDC teams for `operator-1` resolve only to `team-alpha` through the Gateway database.
- Web UI can submit a selected team to API Gateway.

## Steps

1. Complete OIDC login and receive the accessible-team list.
2. Submit forged selection `team-beta`.
3. Submit valid selection `team-alpha`.

## Expected outcome

Gateway rejects `team-beta` and issues no token for it; the `team-alpha` selection returns a working token containing exactly canonical `operator-1`, `team-alpha`, and `Alpha Team`.

- E2E: `qa-e2e/api-gateway/tests/v0007-oidc-team-resolution.spec.ts` and `qa-e2e/api-gateway/tests/v0007-keycloak-compatibility.spec.ts` (test titles containing the stable v0007 ID).
- GREEN: complete API Gateway suite — 30 passed on 2026-08-28.
