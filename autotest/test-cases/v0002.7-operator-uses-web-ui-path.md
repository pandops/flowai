# Test case: v0002.7-operator-uses-web-ui-path

## Implements

`state-registry` — `### Requirement: State Registry records team-scoped gateway-mediated controls`.

## Intent

Verify gateway-mediated controls and rejection of direct operator calls.

## Preconditions

Web UI, trusted API Gateway, and State Registry are running; the operator context contains verified `operator_id`, immutable `team_id = team-a`, display-only `team_name`, and `request_id`; a `team-a` task is assigned.

## Steps

1. Submit a cancellation through Web UI and trusted API Gateway using the verified context.
2. Attempt the equivalent direct State Registry request while supplying copied operator and team headers without the trusted Gateway identity.
3. Query audit and control records through trusted Gateway context for `team-a`.

## Expected outcome

The gateway-mediated request is stored with idempotency scoped to `(team_id, task_id, operator_id, action)` and audited with `request_id`; the direct request is rejected and creates no control or audit-backed domain mutation; and `team_name` grants no authority.
