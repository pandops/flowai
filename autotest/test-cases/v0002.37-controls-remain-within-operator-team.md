# Test case: v0002.37-controls-remain-within-operator-team

## Implements

`state-registry` — `### Requirement: State Registry records team-scoped gateway-mediated controls`.

`state-registry` — `### Requirement: State Registry returns non-revealing not-found for foreign resources`.

## Intent

Verify same-team control creation, idempotency, audit, and assigned-Executor reads while denying a foreign task probe.

## Preconditions

Trusted Gateway context represents a `team-a` operator; `team-a` has a task assigned to `executor-a`; `team-b` has another task.

## Steps

1. Create a cancellation for the `team-a` task through trusted Gateway context and retry the same `(team_id, task_id, operator_id, action)`.
2. Read pending controls as assigned `executor-a`.
3. Attempt the same control action against the `team-b` task.
4. Read controls and audit entries as `team-a`.

## Expected outcome

The same-team request and retry identify one control and one idempotent outcome; assigned `executor-a` reads it; the foreign write returns the unknown-resource `404` shape and creates no control, task event, or disclosed audit row; all returned controls and audits belong only to `team-a`.

`autotest/state-registry/tests/contracts/05-gateway-controls-websocket.spec.ts` — `v0002.37 control creation is team-scoped and idempotent; foreign task control returns non-revealing 404`
