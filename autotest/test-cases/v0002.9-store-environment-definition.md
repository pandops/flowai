# Test case: v0002.9-store-environment-definition

## Implements

`state-registry` — `### Requirement: State Registry stores team-owned environment definitions`.

## Intent

Verify gateway-mediated storage of scoped non-secret environment values.

## Preconditions

Web UI, trusted API Gateway, State Registry, and PostgreSQL are running; the Gateway context contains verified `operator_id`, immutable `team_id = team-a`, display-only `team_name`, and `request_id`.

## Steps

1. Submit a project/task-scoped non-secret environment definition through Web UI and API Gateway for `team-a`.
2. Read the definition through the same trusted team context.
3. Query its team-scoped audit entry.

## Expected outcome

State Registry stores immutable `team_id = team-a`, returns a stable environment identifier, exposes the non-secret values only to same-team reads, and appends an audit entry containing team, operator, request, resource, action, and outcome without secret plaintext; project/task scope cannot grant another team access.

## Implementation reference

`autotest/state-registry/tests/contracts/06-environments-secrets-crypto.spec.ts` — `v0002.9 team-owned environment definition is stored with immutable team_id and exposes non-secret values only`
