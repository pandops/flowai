# Test case: v0002.3-executor-claims-by-tag

## Implements

`state-registry` — `### Requirement: State Registry lists pending tasks by exact tag, scoped to the Executor's eligibility`.

## Intent

Verify exact-tag discovery returns only matching `pending` tasks without reserving or assigning them, that the discovery response is metadata-only (no task payload values, decrypted environment values, secret material, or event history), and that discovery shapes no count, cursor, or pagination metadata that signals foreign rows.

## Preconditions

Two `team-a` `pending` tasks exist; the first has REQUIRED non-null `task_type_id` referencing a same-team task type whose `execution_tag = openhands` and the second has `execution_tag = k8s`; an Executor identity bound to `team-a` is registered with exactly one tag, `openhands`.

## Steps

1. Request `GET /v1/executors/{executor_id}/tasks?tag=openhands` as the registered `team-a` Executor.
2. Request `GET /v1/executors/{executor_id}/tasks?tag=k8s` as the same Executor.
3. Read both canonical task views through trusted API Gateway context for `team-a`.

## Expected outcome

The matching discovery returns `200` with only the same-team `openhands` `pending` summary; the unregistered-tag request is rejected without revealing tasks; both task reads return `200` with immutable `team_id = team-a`, REQUIRED non-null same-team `task_type_id`, server-derived `required_tag`, `current_state = pending`, `resolved_image = null`, `image_source = null`, `claimed_at = null`, and `executor_id = null`. The discovery response is metadata-only; the system-owned Executor does NOT receive task payload values, decrypted environment values, secret material, or event history; payload is delivered only in a successful `200 claimed` response for the assigned task. Discovery changes neither state nor assignment; foreign tasks (foreign-team or wrong-tag) appear with no count, cursor, or pagination metadata.

## Implementation reference

`autotest/state-registry/tests/contracts/02-executor-registration-discovery.spec.ts` — `v0002.3 executor discovers only pending same-team tasks matching the registered exact tag`
