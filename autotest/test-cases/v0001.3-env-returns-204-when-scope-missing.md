# mocked-task-server env endpoint returns 204 when scope is not configured

- **File**: [`autotest/executor_docker_opehands/tests/executor.spec.ts:48`](../../executor_docker_opehands/tests/executor.spec.ts)
- **Style**: Cross-service Playwright (real binaries, no Docker required)

## Setup

Both services spawned. No env scopes are seeded in the mocked task
server.

## Action

`GET /v1/env?executor_id=test&routing_target=openhands&scope_token=missing-scope`
against the mocked task server.

## Assert

- Response status is 204 (No Content)

## Purpose

Confirms the env endpoint correctly signals "no values configured" via
204 (not 200 with an empty body, not 404). The OpenAPI spec for v0001
specifies 204 for "no env values configured". A regression to 200 would
make the executor pass an empty env dict to the container, which the
OpenHands runtime would interpret as "no env" rather than "scope not
configured" — subtle but observable.
