# Test case: v0002.60-admin-creates-team-with-required-default-image

## Implements

`state-registry` — ``### Requirement: State Registry owns team registration through `/admin/teams```.

## Intent

Verify that an authenticated system administrator can create a team through `POST /admin/teams` only when the body contains a unique `team_name` and a required opaque `default_image`; the Registry persists the generated immutable `team_id` plus the unique `team_name` and the required `default_image`.

## Preconditions

State Registry and PostgreSQL are running; no team exists; an authenticated system-administrator identity is configured; no listener, Executor, or Gateway identity may call this endpoint.

## Steps

1. Submit `POST /admin/teams` with a unique `team_name` and a required opaque `default_image` as the authenticated system administrator.
2. Read back the returned canonical team record.
3. Submit `POST /admin/teams` again with the same `team_name` and observe the response.
4. Submit `POST /admin/teams` without `default_image` and observe the response.
5. Submit `POST /admin/teams` without `team_name` and observe the response.

## Expected outcome

The first request returns `201` with a generated immutable `team_id`, the supplied unique `team_name`, and the required `default_image`; the team row is durable across restart. The duplicate-`team_name`, missing-`default_image`, and missing-`team_name` requests are each rejected without creating or partially persisting a team.
