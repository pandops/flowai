# executor pulls the image, creates a labeled container, and cleans up on health-check failure

- **File**: [`autotest/executor_docker_opehands/tests/container-execution.spec.ts:89`](../../executor_docker_opehands/tests/container-execution.spec.ts)
- **Style**: Cross-service Playwright (real binaries + real Docker daemon)

## Setup

- Spawn a TCP→UNIX socket proxy that forwards to the local Docker
  daemon (rootless podman at `/run/user/1000/podman/podman.sock`).
- Spawn `mocked-task-server` on port 18081 and `executor_docker_opehands` on
  port 18021, with `DOCKER_SOCKET_PATH` pointing at the proxy and
  `OPENHANDS_IMAGE=agent-openhands-image:latest`.
- Use alt ports to avoid collision with the wire-contract tests.
- Set `OPENHANDS_STARTUP_TIMEOUT_SECONDS=30` (V1 agent-server takes
  ~10–15s to become ready).
- Set the host port range to `[20000, 20010]`.
- Enable the test-mode endpoints on the mocked task server
  (`MOCKED_SERVER_TEST_MODE=true`).
- Seed a queued task via `POST /v1/_test/tasks` with a known `task_id`.
- Clean up any leftover containers with the executor's `flowai.executor_id`
  label from previous runs (idempotency across re-runs).

## Action

1. Poll the executor's `/v1/livez` to discover the generated
   `executor_id`.
2. Poll the Docker daemon's
   `/v1.41/containers/json?all=true&filters={label:[flowai.executor_id=…]}`
   until a container with our label appears (up to 60 s).
3. Inspect the container's `Image` and `Labels`.
4. Poll the Docker daemon again until the container is gone (up to
   20 s).

## Assert

- The container exists with the configured `agent-openhands-image`
  in its `Image` (Docker may canonicalize the name with
  `docker.io/library/` prefix — the assertion uses substring match).
- The container's labels include all three required keys:
  - `flowai.executor_id` equals the discovered `executor_id`
  - `flowai.runtime` equals `"openhands"`
  - `flowai.task_id` equals the seeded `task_id`
- After the cleanup deadline, no containers with the executor's
  label remain.

## Purpose

Proves **end-to-end** that the executor:

1. Talks to a **real** Docker daemon (not in-process fakes) — proven by
   the container appearing in the daemon's `/containers/json` response
   over a real UNIX socket via the TCP proxy.
2. Creates containers with the **correct labels** that the startup
   cleanup and the Docker event filter use to find this executor's
   containers.
3. Submits the task to OpenHands — the `task.started` and
   `task.start_message` events are journaled to the mocked task server
   before the container is cleaned up. (Implicit: the executor's
   `tailOpenHandsLogs` only starts the polling after `task.started` and
   `task.start_message` are journaled, so a container's existence on
   the daemon implies the events were posted.)
4. Cleans up containers on shutdown — proven by the empty list of
   labeled containers after the cleanup deadline.

This is the only test in the suite that exercises a real container
lifecycle. The 8 wire-contract tests above verify protocol correctness
without requiring Docker; this test verifies that the protocol
correctness translates into actual side effects on a real daemon.
