# Test case: v0009.1-precommit-rejects-unformatted-change

## Implements

`developer-tooling` — `### Requirement: Repository blocks commits that fail quality gates`.

## Intent

Verify that the repository quality command rejects an unformatted staged Go
file before Git creates a commit.

## Preconditions

Pinned Node dependencies and golangci-lint are installed.

## Steps

1. Stage an intentionally unformatted Go file in a disposable Git repository.
2. Run the repository staged-file quality check.
3. Format and restage the file, then rerun the check.

## Expected outcome

The first check fails with a gofmt diagnostic and the second succeeds.

## Implementation reference

`autotest/scripts/test-quality-hook.sh` — `precommit rejects unformatted staged Go`
