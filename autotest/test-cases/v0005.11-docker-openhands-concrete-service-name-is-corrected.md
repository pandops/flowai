# Test case: v0005.11-docker-openhands-concrete-service-name-is-corrected

## Implements

`executor` — `### Requirement: Docker OpenHands concrete service uses the correctly spelled identifier`.

## Intent

Verify the existing Docker OpenHands concrete Executor is corrected from
`executor_docker_openhands` to `executor_docker_openhands` consistently across
its filesystem, executable surface, and State Registry wire registration,
while keeping the Go constant name `ExecutorTypeDockerOpenHands`. The old
wire value has no compatibility alias, and archived OpenSpec artifacts remain
historical records rather than current runtime inputs.

## Preconditions

The repository has been renamed according to the implementation plan. State
Registry and PostgreSQL are running. The Docker runtime required by the
Executor test harness is available, and a Docker Executor is configured
with a valid team, tag, and no certificate files. v0009: backend
transport is plain HTTP; the State Registry does not authenticate the
Executor connection — the deployment network policy owns the
Executor-caller boundary.

## Steps

1. Assert the current repository contains
   `executor_docker_openhands/cmd/executor_docker_openhands/`,
   `executor_docker_openhands/configs/executor_docker_openhands.yaml`, and
   `autotest/executor_docker_openhands/`, and that the corresponding
   misspelled non-archived paths do not exist.
2. Build and start the `executor_docker_openhands` binary using the renamed
   config and capture its registration request to State Registry.
3. Read the registered Executor record and inspect the binary's structured
   startup log and health-probe response.
4. Run the platform-package regression test that evaluates
   `ExecutorTypeDockerOpenHands`.
5. Search non-archived source, current documentation, fixtures, scripts, and
   active OpenSpec artifacts for the old identifier.

## Expected outcome

The renamed binary starts from the renamed directory/config paths and
registers `executor_type = "executor_docker_openhands"`. The canonical
Executor read returns that exact value; structured logs and probes use
`executor_docker_openhands`; `ExecutorTypeDockerOpenHands` evaluates to
`"executor_docker_openhands"`; and no non-archived current-state source
contains `executor_docker_openhands`. Archived OpenSpec change artifacts may
retain the old spelling as immutable historical evidence. No compatibility
registration or alias exposes the old wire value.

## Implementation reference

autotest/executor_k8s_openhands/tests/v0005.11-docker-openhands-concrete-service-name-is-corrected.spec.ts (v0005.11 docker openhands concrete service name is corrected); RED evidence: misspelled directory and wire value; GREEN evidence: executor_docker_openhands/ rename + executor_docker_openhands/internal/platform/types.go (ExecutorTypeDockerOpenHands = 'executor_docker_openhands').
