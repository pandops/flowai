# Test case: v0002.64-required-team-default-image-is-always-present

## Implements

`state-registry` — `### Requirement: State Registry requires a default image at team registration`.

## Intent

Verify that every team row has a non-null `default_image` because team registration requires it; no admin or operator path can clear or change `default_image` (corrections require registering a new team).

## Preconditions

State Registry and PostgreSQL are running.

## Steps

1. Confirm rejection of `POST /admin/teams` when `default_image` is omitted.
2. Create `team-a` with `default_image = img-a`.
3. Read `team-a` and confirm `default_image = img-a`.
4. Attempt every operator-side update path (`PUT /v1/teams/me/default-image` and any equivalent path) and confirm that no operator path can mutate or clear `default_image`; the team's required `default_image` is the only change mechanism.
5. Submit a claim against a new `team-a` task with no `tasks.image` override and confirm `resolved_image = img-a` and `image_source = team_default`.

## Expected outcome

Every team row has a non-null `default_image`; no operator path can clear or change it; resolution succeeds for every claim because the team default is required; `image_source = team_default` is recorded for the team-default-only case.
