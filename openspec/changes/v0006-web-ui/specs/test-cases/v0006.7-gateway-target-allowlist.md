# Test case: v0006.7-gateway-target-allowlist

## Implements

`api-gateway` — `### Requirement: Gateway routes only to allowed backend services`

## Intent

Failure-path test verifying that the no-auth Gateway cannot proxy to an Executor or arbitrary backend.

## Preconditions

- Gateway is configured with `operator_id=bootstrap-operator` for `team-alpha` and State Registry.
- Test Executor and arbitrary HTTP endpoints record incoming calls.

## Steps

1. Send a valid Web UI-shaped request targeting a State Registry route.
2. Attempt equivalent requests targeting an Executor route and an arbitrary backend URL.
3. Inspect all backend call observations.

## Expected outcome

Only the State Registry receives a configured bootstrap operator + configured-team child request; forbidden targets receive no call and the Gateway returns a rejection.
