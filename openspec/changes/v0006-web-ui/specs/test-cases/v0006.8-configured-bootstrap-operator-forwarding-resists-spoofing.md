# Test case: v0006.8-configured-bootstrap-operator-forwarding-resists-spoofing

## Implements

`api-gateway` — `### Requirement: Gateway establishes trusted configured-team context`

## Intent

Security test verifying that the Gateway replaces every forged browser identity/context header with the configured bootstrap `operator_id`, the configured `team_id`, the display-only `team_name`, and a Gateway-generated request ID.

## Preconditions

- Gateway is configured with `operator_id=bootstrap-operator`, `team_id=team-alpha`, and `team_name=Alpha Team`.
- State Registry test endpoint returns the trusted child-request headers it receives.

## Steps

1. Send a REST request with forged `X-FlowAI-Operator-ID=attacker`, `X-FlowAI-Team-ID=team-beta`, `X-FlowAI-Team-Name=Beta Team`, and `X-FlowAI-Request-ID=chosen-id`.
2. Capture the State Registry child request.

## Expected outcome

State Registry receives `X-FlowAI-Operator-ID: bootstrap-operator`, `X-FlowAI-Team-ID: team-alpha`, `X-FlowAI-Team-Name: Alpha Team`, and a non-empty Gateway-generated request ID different from `chosen-id`; no forged header value and no browser credential are present.
