# Test case: v0006.3-no-auth-action-uses-configured-bootstrap-operator-and-team

## Implements

`web-ui` — `### Requirement: Operator actions use configured-team no-auth gateway-mediated APIs`

## Intent

Happy path verifying that an operator action succeeds without login, remains scoped to the deployment-configured team, and is attributed to the configured bootstrap `operator_id`.

## Preconditions

- Gateway bootstrap configuration identifies `operator_id=bootstrap-operator` and `team_id=team-alpha`.
- State Registry contains a `team-alpha` environment and a distinct `team-beta` environment.

## Steps

1. Open the environment page without authenticating.
2. Update the `team-alpha` environment through the Web UI.
3. Read both teams' environment records through authorized State Registry test setup.

## Expected outcome

The Web UI submits no selected or overridden team identity and no operator identity, the `team-alpha` environment is updated with audit attribution to `bootstrap-operator` and a Gateway-generated `request_id`, and the `team-beta` environment remains unchanged.
