# Test case: v0006.11-response-remains-unchanged

## Implements

`api-gateway` — `### Requirement: Gateway remains business-logic-free`

## Intent

Happy-path and denial-path test verifying that request-side security enrichment (including configured bootstrap operator + team context) does not transform State Registry responses.

## Preconditions

- Gateway is configured with `operator_id=bootstrap-operator` for `team-alpha`.
- State Registry fixtures can return a distinctive success response and a distinctive ownership denial.

## Steps

1. Request a `team-alpha` task whose fixture returns a known status, headers, and JSON body.
2. Request a resource whose fixture returns a known ownership-denial status, headers, and body.
3. Compare each State Registry response with the corresponding Gateway response.

## Expected outcome

For both requests, status, response headers, and body are byte-for-byte equivalent across the Gateway boundary, with no added platform fields, aggregation, caching artifact, or policy substitution.
