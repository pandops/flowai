# Test case: v0006.4-browser-does-not-assert-internal-context

## Implements

`web-ui` — `### Requirement: Web UI does not assert internal identity context`

## Intent

Security test verifying that normal browser traffic does not originate trusted downstream identity headers, including `X-FlowAI-Operator-ID`, and does not assert the configured bootstrap `operator_id`.

## Preconditions

- Web UI is loaded in a browser with request inspection enabled.
- API Gateway is running in configured bootstrap-operator + configured-team no-auth mode.

## Steps

1. Trigger a task-history REST request from the Web UI.
2. Trigger a live-event WebSocket upgrade from the Web UI.
3. Inspect the browser-originated headers for both requests.

## Expected outcome

Neither browser request contains `X-FlowAI-Operator-ID`, `X-FlowAI-Team-ID`, `X-FlowAI-Team-Name`, `X-FlowAI-Request-ID`, or an equivalent internal identity/context header. Neither browser request contains the configured bootstrap `operator_id` or any other operator identifier.
