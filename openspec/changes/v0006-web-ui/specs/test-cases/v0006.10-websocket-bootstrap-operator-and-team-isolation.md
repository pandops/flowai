# Test case: v0006.10-websocket-bootstrap-operator-and-team-isolation

## Implements

`api-gateway` — `### Requirement: Gateway establishes trusted configured-team context`

## Intent

Security test verifying that a WebSocket subscription uses the configured bootstrap `operator_id` and configured `team_id` and cannot receive another team's events.

## Preconditions

- Gateway is configured with `operator_id=bootstrap-operator` for `team-alpha`.
- State Registry can publish distinguishable `team-alpha` and `team-beta` events.

## Steps

1. Open a WebSocket with forged `X-FlowAI-Operator-ID=attacker`, `X-FlowAI-Team-ID=team-beta`, and other forged internal context headers.
2. Publish one event for `team-alpha` and one event for `team-beta`.
3. Observe the child subscription context and browser event frames.

## Expected outcome

The child subscription contains Gateway-established `bootstrap-operator`, `team-alpha`, and a generated request ID, with no forged values and no browser bearer credential. The browser receives the `team-alpha` event but never the `team-beta` event.
