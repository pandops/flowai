# Test case: v0006.5-refresh-rebuilds-team-view

## Implements

`web-ui` — `### Requirement: Client state is non-authoritative`

## Intent

Edge-case test verifying that a browser refresh rebuilds the configured bootstrap operator + configured-team view from Gateway/State Registry state rather than stale client authority.

## Preconditions

- Web UI displays a `team-alpha` task attributed to `bootstrap-operator` from State Registry.
- The test can update that task through the supported State Registry fixture/API between browser actions.

## Steps

1. Open the task detail and record its displayed status.
2. Change the task status in State Registry through the supported test setup.
3. Refresh the browser page.

## Expected outcome

The refreshed page displays the new Gateway-provided task status and configured team context, with no stale locally authoritative task, operator, team, event, audit, routing, or secret state.
