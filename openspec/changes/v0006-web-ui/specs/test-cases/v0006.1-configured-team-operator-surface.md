# Test case: v0006.1-configured-team-operator-surface

## Implements

`web-ui` — `### Requirement: Web UI renders the configured-team operator surface`

## Intent

Happy path verifying that bootstrap mode presents exactly one configured team as display context without team-management controls, and that the Web UI never asserts the configured bootstrap `operator_id`.

## Preconditions

- API Gateway is running in no-auth bootstrap mode with `operator_id=bootstrap-operator`, `team_id=team-alpha`, and canonical `team_name=Alpha Team`.
- Web UI is configured with the API Gateway as its only backend.

## Steps

1. Open the Web UI dashboard in a browser without credentials.
2. Inspect the visible team context, available navigation/actions, and any visible operator identifier.

## Expected outcome

The dashboard displays `Alpha Team`, renders task, control, environment, and
secret operator surfaces, and contains no team selector, team CRUD,
membership-management, source-system registration, task-type registration,
or global admin projection control. No browser request targets `/admin/*`.
The configured bootstrap `operator_id` is not displayed, logged, selectable,
or otherwise exposed by the Web UI.
