# Test case: v0006.2-gateway-only-browser-backend

## Implements

`web-ui` — `### Requirement: API Gateway is the only backend`

## Intent

Failure-path topology test verifying that browser flows never call State Registry or an Executor directly and never assert the configured bootstrap `operator_id`.

## Preconditions

- Web UI and API Gateway are running on distinct origins from State Registry and Executor test endpoints.
- Browser network capture is enabled.

## Steps

1. Open task history and task detail in the Web UI.
2. Start the live-event view.
3. Submit a control request and an environment update.
4. Collect all browser HTTP and WebSocket destinations and any browser-originated operator identifier.

## Expected outcome

Every backend HTTP request and WebSocket upgrade targets the configured API Gateway origin; zero browser requests target State Registry, an Executor, or any other backend origin, and zero browser requests contain `X-FlowAI-Operator-ID` or the configured bootstrap `operator_id`.
