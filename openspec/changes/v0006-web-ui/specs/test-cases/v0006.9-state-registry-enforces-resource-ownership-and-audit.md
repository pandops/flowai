# Test case: v0006.9-state-registry-enforces-resource-ownership-and-audit

## Implements

`api-gateway` — `### Requirement: State Registry remains authoritative for resource ownership`

## Intent

Security test verifying that the Gateway supplies configured bootstrap operator + team context while State Registry, not the Gateway or display name, decides ownership, and that audit attribution uses the trusted configured bootstrap `operator_id`.

## Preconditions

- Gateway is configured with `operator_id=bootstrap-operator`, `team_id=team-alpha`, and `team_name=Shared Display Name`.
- State Registry has a resource owned by `team-beta`, whose canonical display name is also `Shared Display Name`.

## Steps

1. Request the `team-beta` resource through the configured `team-alpha` Gateway.
2. Submit a control request for a `team-alpha` resource and inspect the resulting audit entry.
3. Capture the State Registry decision and the Gateway response.

## Expected outcome

State Registry evaluates ownership using `team-alpha`, denies access despite the matching display name, and the Gateway forwards the denial unchanged. The accepted mutation's audit entry is attributed to `bootstrap-operator` plus the gateway-generated `request_id`, never to a browser-supplied operator value or to the display name.
