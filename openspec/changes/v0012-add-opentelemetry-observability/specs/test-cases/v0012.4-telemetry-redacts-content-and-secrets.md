# Test case: v0012.4-telemetry-redacts-content-and-secrets

## Implements

`platform-observability` — `### Requirement: Telemetry excludes sensitive and content-bearing data by default`.

## Intent

Verify the privacy failure path using unique markers across all content-bearing
and credential surfaces.

## Preconditions

- The full E2E stack exports through a Collector whose received and forwarded
  telemetry can be inspected.
- Distinct unique markers are placed in task payload, prompt, environment
  plaintext, authorization, session key, tool output, and a dependency error
  body.

## Steps

1. Execute one successful and one failing task that exercise OpenHands LLM/tool
   tracing and State Registry/Executor dependency errors.
2. Inspect exported traces, metrics, correlated logs, Collector diagnostics,
   and exporter failure messages as raw serialized data.
3. Search every inspected signal for every unique marker.

## Expected outcome

No marker appears in any telemetry or diagnostic output; spans retain only
allowed identifiers, normalized operation metadata, status, durations, and
bounded sanitized error classes; and the tasks retain their expected canonical
success or failure outcomes.
