# Test case: v0012.2-durable-task-phases-use-links-not-open-waits

## Implements

`platform-observability` — `### Requirement: Durable task phases use finite spans and explicit correlation`.

## Intent

Verify the asynchronous edge case that a task waiting durably does not retain
an ingestion span and later execution is represented with explicit correlation.

## Preconditions

- The instrumented E2E stack and inspectable Collector are running with no
  eligible Executor initially available.
- A listener can submit a task and an Executor can be started later.

## Steps

1. Submit a task and wait until its listener request has returned and its
   ingestion span is exported.
2. Keep the task pending beyond the ingestion request duration.
3. Start the eligible Executor, allow claim and execution, and inspect the
   resulting spans.

## Expected outcome

The ingestion span has ended before the pending wait finishes; no ingestion,
discovery, or claim span covers the durable wait or full execution; the task
execution span contains canonical task, command, and Executor identifiers and a
valid link to available producer or claim context; and task lifecycle remains
canonical.
