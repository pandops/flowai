# Test case: v0007.6-authenticated-actions-use-gateway-only

## Implements

`web-ui` — `### Requirement: Operator actions carry the selected team identifier`

## Intent

Authenticated happy-path test verifying that the browser bearer is used only with API Gateway and actions remain bound to its one token team.

## Preconditions

- Web UI is signed in with a `team-alpha` token.
- Browser network capture is enabled and State Registry contains separate `team-alpha` and `team-beta` tasks.

## Steps

1. Read `team-alpha` task history and submit a control request through the Web UI.
2. Inspect all browser request destinations and authorization headers.
3. Inspect both teams' State Registry state through authorized fixtures.

## Expected outcome

The browser sends its bearer only to API Gateway, never directly to State Registry or an Executor; only the `team-alpha` task is read or mutated and `team-beta` remains unchanged.
