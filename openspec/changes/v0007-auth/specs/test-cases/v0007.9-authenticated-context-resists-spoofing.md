# Test case: v0007.9-authenticated-context-resists-spoofing

## Implements

`api-gateway` — `### Requirement: Gateway establishes trusted configured-team context`

## Intent

Security test verifying that canonical operator/team claims replace forged browser context on authenticated REST requests.

## Preconditions

- A valid bearer token contains canonical `operator_id=operator-1`, `team_id=team-alpha`, and `team_name=Alpha Team`.
- State Registry returns the child-request headers it receives.

## Steps

1. Send an authenticated REST request with forged `X-FlowAI-Operator-ID=attacker`, `X-FlowAI-Team-ID=team-beta`, `X-FlowAI-Team-Name=Beta Team`, and `X-FlowAI-Request-ID=chosen-id`.
2. Capture the State Registry child request.

## Expected outcome

State Registry receives `operator-1`, `team-alpha`, optional display-only `Alpha Team`, and a non-empty Gateway-generated request ID different from `chosen-id`; no forged header value is present.
