# Test case: v0007.2-invalid-or-stale-token-rejected

## Implements

`auth` — `### Requirement: Gateway validates operator and team claims`

## Intent

Failure-path test verifying audience, expiry, operator/team shape, and stale assignment checks before proxying.

## Preconditions

- State Registry records all child requests and subscriptions.
- Test tokens can be issued with wrong audience, past expiry, missing operator, multiple team identities, and a formerly valid but now inactive team assignment.

## Steps

1. Send protected REST requests with each invalid token variant.
2. Attempt a WebSocket upgrade with the stale-team token.
3. Inspect State Registry observations.

## Expected outcome

Every request/upgrade is rejected by API Gateway and State Registry observes no child REST request or WebSocket subscription.
