# Test case: v0007.16-keycloak-groups-are-canonical

## Implements

`api-gateway` — `### Requirement: Gateway obtains canonical groups from Keycloak`

## Intent

Security test verifying that browser-supplied groups cannot broaden the teams resolved for a user.

## Preconditions

- Keycloak authenticates `operator-1` with only `group-alpha`.
- State Registry maps `group-alpha` to `team-alpha` and `group-beta` to `team-beta`.
- State Registry records the group identifiers received from Gateway.

## Steps

1. Start login through Web UI and API Gateway.
2. Add forged `group-beta`, `team-beta`, and operator values to the browser callback or follow-up request.
3. Complete Keycloak authentication and inspect State Registry observations and the Gateway response.

## Expected outcome

State Registry receives only canonical `operator-1` and `group-alpha`; the response contains only `team-alpha`, and no forged value reaches the trusted resolution request.
