# Test case: v0007.12-unusable-team-context-fails-closed

## Implements

`api-gateway` — `### Requirement: Gateway rejects unusable authenticated team context`

## Intent

Failure-path test verifying missing, ambiguous, and stale team context is rejected consistently before REST or WebSocket proxying.

## Preconditions

- Tokens exist with missing team identity, duplicate/conflicting team identity, and a validly signed but inactive team assignment.
- State Registry records every child request and subscription.

## Steps

1. Send protected REST requests with each unusable token.
2. Attempt protected WebSocket upgrades with each unusable token.
3. Inspect State Registry observations.

## Expected outcome

All REST requests and WebSocket upgrades are rejected before proxying and State Registry observes no child request or subscription.
