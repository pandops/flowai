# Test case: v0007.19-unresolved-team-selection-is-rejected

## Implements

`api-gateway` — `### Requirement: Gateway resolves groups to teams through State Registry`

## Intent

Security test verifying that Gateway issues a working token only for a team in fresh State Registry resolution.

## Preconditions

- Keycloak groups for `operator-1` resolve only to `team-alpha`.
- Web UI can submit a selected team to API Gateway.

## Steps

1. Complete Keycloak login and receive the accessible-team list.
2. Submit forged selection `team-beta`.
3. Submit valid selection `team-alpha`.

## Expected outcome

Gateway rejects `team-beta` and issues no token for it; the `team-alpha` selection returns a working token containing exactly canonical `operator-1`, `team-alpha`, and `Alpha Team`.
