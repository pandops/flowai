# Test case: v0007.18-team-registration-binds-keycloak-group

## Implements

`state-registry` — ``### Requirement: State Registry owns team registration through `/admin/teams` ``

## Intent

Happy-path and conflict test verifying immutable unique Keycloak group mapping at team registration.

## Preconditions

- An authenticated system administrator exists.
- `group-alpha` is not mapped and `group-existing` is already mapped.

## Steps

1. Create `Alpha Team` with `group-alpha` and a valid default image.
2. Attempt to create another team with `group-existing`.
3. Read the persisted team mapping through the supported administrative verification surface.

## Expected outcome

The first request returns a canonical team with immutable `team_id`, `team_name`, `keycloak_group_id`, and `default_image`; the duplicate mapping is rejected without partial persistence.
