# Test case: v0007.3-session-team-is-immutable

## Implements

`auth` — `### Requirement: Auth session has one immutable active team`

## Intent

Security test verifying that refresh and browser input cannot switch the active team within a session.

## Preconditions

- Operator token/session is bound to `team-alpha`.
- Canonical auth state can be changed to `team-beta` during the test.

## Steps

1. Request refresh while supplying a browser-selected `team-beta` value.
2. Change the canonical assignment from `team-alpha` to `team-beta`.
3. Attempt another refresh of the original session.

## Expected outcome

The Gateway never returns a refreshed token that changes the original immutable `team-alpha` claim; both switch attempts are rejected and a new login is required.
