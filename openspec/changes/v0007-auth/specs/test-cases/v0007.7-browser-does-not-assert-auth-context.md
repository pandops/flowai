# Test case: v0007.7-browser-does-not-assert-auth-context

## Implements

`web-ui` — `### Requirement: Web UI does not assert internal identity context`

## Intent

Security test verifying that authenticated browser requests carry a bearer credential but no trusted downstream identity headers.

## Preconditions

- Web UI has an authenticated `team-alpha` session.
- Browser HTTP and WebSocket requests can be inspected before Gateway handling.

## Steps

1. Trigger an authenticated task-history REST request.
2. Trigger an authenticated live-event WebSocket upgrade.
3. Inspect browser-originated headers.

## Expected outcome

Both requests carry the Gateway bearer credential and contain no `X-FlowAI-Operator-ID`, `X-FlowAI-Team-ID`, `X-FlowAI-Team-Name`, `X-FlowAI-Request-ID`, or equivalent internal identity/context header.
