# Test case: v0002.16-executor-uses-state-registry-openapi

## Implements

`executor` — `### Requirement: Docker Executor API contract is documented as OpenAPI`.

## Intent

Verify Executor client requests conform to the consolidated State Registry contract.

## Preconditions

The State Registry OpenAPI conformance harness is running with a Docker Executor identity bound to one immutable `team_id` and one tag.

## Steps

1. Exercise registration, same-team exact-tag discovery, approval, task and self events, control reads, and team-bound open-environment calls from the Executor.
2. Exercise documented foreign point identifiers and collection discovery outcomes.

## Expected outcome

Every request and response validates against State Registry OpenAPI, including one-team identity, the explicit `team_id` field on every Executor-emitted task and self event envelope that State Registry verifies against the authenticated Executor team, non-revealing `404` for foreign point identifiers, empty/`204` same-team discovery when only foreign tasks match, and complete scope-token claims; no Router or Env Registry contract is used.
