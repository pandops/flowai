# Test case: v0002.2-listener-deduplicates-task

## Implements

`state-registry` — `### Requirement: State Registry deduplicates listener tasks within a team`.

## Intent

Verify idempotent external-task ingestion.

## Preconditions

State Registry is running; the listener identity is authorized for `team-a`; no task exists for deduplication key `(team-a, jira, JIRA-142)`.

## Steps

1. Submit a task with `team_id = team-a`, source `jira`, and source task identifier `JIRA-142`.
2. Repeat the same team-scoped submission.
3. Query tasks and events for that key through trusted Gateway context for `team-a`.

## Expected outcome

Both submissions identify the same canonical task with immutable `team_id = team-a`; exactly one task record and one `created` event exist for `(team-a, jira, JIRA-142)`; and retrying does not reset task state or history.
