# Test case: v0002.34-discovery-isolates-team-before-pagination

## Implements

`state-registry` — `### Requirement: State Registry lists created tasks by team and required tag`.

## Intent

Verify collection discovery applies same-team and exact-tag predicates before result shaping and reveals nothing when only foreign tasks match.

## Preconditions

A `team-b` `created` task has tag `openhands`; no `team-a` task matches; a `team-a` Executor is registered with exactly tag `openhands`.

## Steps

1. Request discovery as the `team-a` Executor with its registered tag, a one-item page limit, and no cursor.
2. Repeat with any cursor returned by the first response.
3. Read the foreign task directly using the `team-a` Executor identity.

## Expected outcome

Discovery returns `204` or an empty collection with no foreign row and no count, total, cursor, or pagination metadata that signals the `team-b` task. The point probe returns the same non-revealing `404` shape as an unknown task, and no state or assignment changes.
