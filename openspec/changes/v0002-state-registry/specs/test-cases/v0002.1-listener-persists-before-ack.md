# Test case: v0002.1-listener-persists-before-ack

## Implements

`state-registry` — `### Requirement: State Registry is the canonical team-scoped task source`.

## Intent

Verify that listener acknowledgement follows durable task persistence.

## Preconditions

State Registry and PostgreSQL are running; the listener identity is bound to immutable `team_id = team-a`; no task exists for `(team-a, jira, JIRA-142)`.

## Steps

1. Submit task `jira/JIRA-142` with `team_id = team-a` through the listener ingestion API.
2. Observe the successful response and immediately read the task as trusted Gateway context for `team-a`.
3. Restart State Registry and query the returned task identifier as the same team.

## Expected outcome

The listener receives success only after the task row with immutable `team_id = team-a` and its `created` event commit in one transaction, and the canonical team-owned task remains readable after restart.
