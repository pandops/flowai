# Test case: v0002.14-executor-registers-with-state-registry

## Implements

`executor` — `### Requirement: Docker Executor registers with the State Registry`.

## Intent

Verify authenticated Executor registration with exactly one tag and complete lifecycle-event reporting.

## Preconditions

State Registry trusts a Docker Executor service identity bound to immutable `team_id = team-a`, and the Executor is configured with the single tag `openhands`.

## Steps

1. Start the Executor and capture its `PUT /v1/executors/{executor_id}` registration containing `team_id = team-a`.
2. Capture its startup and health events posted to `POST /v1/executors/{executor_id}/events`.
3. Read its canonical Executor record and event history through trusted Gateway context for `team-a`.

## Expected outcome

Registration returns `200`; the record has immutable `team_id = team-a`, the authenticated identity, Docker Executor type, exactly `authorized_tag = openhands`, observed capacity fields, and runtime metadata. Every self event envelope returns `202 accepted`, includes non-null `executor_id`, includes `team_id = team-a` matching the authenticated Executor team that State Registry verifies, and preserves its submitted event fields.
