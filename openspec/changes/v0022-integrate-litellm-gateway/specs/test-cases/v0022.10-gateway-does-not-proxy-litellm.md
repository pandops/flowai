# Test case: v0022.10-gateway-does-not-proxy-litellm.md

## Implements

`api-gateway` — `### Requirement: API Gateway forwards team-scoped target-reference operations only`.

## Intent

Verify Gateway adds canonical team context only for catalog operations and rejects every LiteLLM proxy path.

## Preconditions

Two operator teams and request capture on State Registry and LiteLLM exist.

## Steps

1. Submit a same-team target operation with a forged team field.
2. Request LiteLLM login, management, inference, and A2A paths through Gateway.
3. Inspect downstream request records.

## Expected outcome

State Registry receives verified rather than forged context; all LiteLLM paths are rejected and LiteLLM receives no request.
