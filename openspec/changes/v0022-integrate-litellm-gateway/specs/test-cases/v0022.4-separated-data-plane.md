# Test case: v0022.4-separated-data-plane.md

## Implements

`litellm-gateway` — `### Requirement: LiteLLM separates management and authenticated data planes`.

## Intent

Verify network and authentication policy separates workloads from administration and redacts failures.

## Preconditions

An authorized workload, an unauthorized workload, valid/invalid virtual keys, and a credential-bearing upstream error fixture exist.

## Steps

1. Call a model without a key and with an invalid key.
2. Call a management route from the workload network.
3. Call through the valid key and trigger the credential-bearing upstream error.
4. Inspect client error and captured logs.

## Expected outcome

Invalid calls never reach upstream, workload management access is denied, and neither returned errors nor logs contain any seeded credential.
