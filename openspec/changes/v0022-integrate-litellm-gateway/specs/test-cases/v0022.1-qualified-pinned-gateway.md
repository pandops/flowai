# Test case: v0022.1-qualified-pinned-gateway.md

## Implements

`litellm-gateway` — `### Requirement: FlowAI deploys a qualified LiteLLM gateway artifact`.

## Intent

Verify the dependency gate rejects a floating or behaviorally broken image and accepts the exact qualified digest.

## Preconditions

A candidate exact LiteLLM image, a deliberately floating tag, and the production-image harness exist.

## Steps

1. Attempt deployment with the floating tag and record the policy rejection.
2. Build the pinned candidate image and run the mandatory qualification probes.
3. Start the deployed artifact and read its immutable image identity.

## Expected outcome

The floating tag never starts; the accepted service reports and runs the exact digest that passed every qualification probe.
