# Test case: v0022.3-persistent-admin-targets.md

## Implements

`litellm-gateway` — `### Requirement: Upstream Admin UI manages persistent targets`.

## Intent

Verify official UI changes for model and A2A targets persist and secrets remain masked.

## Preconditions

Qualified model and A2A fake upstreams and dedicated administrator credentials exist.

## Steps

1. Create and update one model and one supported A2A target in the official UI.
2. Confirm submitted secret fields are masked in list/detail views.
3. Restart LiteLLM without replacing the database.
4. Invoke both aliases, then disable them and invoke again.

## Expected outcome

Both updated aliases work after restart; no submitted secret is returned; disabled aliases reject new calls without rerouting.
