# Test case: v0022.5-typed-routing-no-fallback.md

## Implements

`litellm-gateway` — `### Requirement: LiteLLM routes typed model and A2A targets without fallback`.

## Intent

Verify exact typed aliases route correctly and all failure modes avoid fallback.

## Preconditions

Qualified model/A2A fakes record every request; alternate provider routes are deny-and-record fixtures.

## Steps

1. Invoke the exact model alias and exact A2A alias with valid keys.
2. Invoke missing, incompatible, disabled, and unreachable aliases.
3. Inspect every upstream and alternate-route request record.

## Expected outcome

Successful calls reach only their exact typed target; every negative call has an explicit bounded failure and no alternate/provider-direct request exists.
