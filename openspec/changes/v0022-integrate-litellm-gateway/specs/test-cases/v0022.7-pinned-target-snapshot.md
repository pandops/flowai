# Test case: v0022.7-pinned-target-snapshot.md

## Implements

`state-registry` — `### Requirement: State Registry snapshots LiteLLM execution selection`.

## Intent

Verify a task pins one target revision and only its assignee can open runtime data.

## Preconditions

A task type selects target revision A; revision B can be created; two registered Executors exist.

## Steps

1. Ingest a task using revision A.
2. Create revision B and disable A.
3. Discover the task and attempt environment open as the unassigned Executor.
4. Claim with the eligible Executor and open its environment.

## Expected outcome

All projections hide target secret data; the unassigned open is non-revealing; the assignee receives alias A and its pinned credential version, never revision B.
