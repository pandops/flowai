# Test case: v0022.2-separate-admin-password.md

## Implements

`litellm-gateway` — `### Requirement: LiteLLM administration has separate password-protected access`.

## Intent

Verify the separate administrator origin rejects absent, wrong, and FlowAI-only credentials and accepts the dedicated password.

## Preconditions

A deployed administrator origin, one FlowAI operator session, and dedicated LiteLLM credentials exist.

## Steps

1. Request a protected page without a session.
2. Submit an incorrect password repeatedly through the bounded test allowance.
3. Request it with only the FlowAI session.
4. Authenticate through the dedicated ingress password gate and then through the explicit upstream LiteLLM UI login.

## Expected outcome

The first three paths reveal no upstream UI content or configuration, failed ingress login is rate-limited, and only both dedicated logins return a bounded administrator session.
