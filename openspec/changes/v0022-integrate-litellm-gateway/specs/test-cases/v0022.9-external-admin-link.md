# Test case: v0022.9-external-admin-link.md

## Implements

`web-ui` — `### Requirement: Web UI keeps LiteLLM administration separate`.

## Intent

Verify the configured admin link opens another origin without forwarding FlowAI authentication.

## Preconditions

Web UI has an administrator URL and the browser has a valid FlowAI session but no LiteLLM session.

## Steps

1. Activate the LiteLLM administration link.
2. Inspect destination origin, request headers, and page state.

## Expected outcome

A separate HTTPS origin opens at its LiteLLM login page; no FlowAI bearer token or cookie authenticates the destination.
