# Test case: v0018.3-reconnect-and-team-isolation

## Implements

- `web-ui`: `Web UI renders an actionable task dashboard`

## Intent

Prove that reconnect and selected-team changes reconcile the projection without
losing commits, duplicating cards, or accepting stale foreign-team work.

## Preconditions

- The Web UI image is built from current source and runs in a fresh container.
- A deterministic containerized adapter fixture can interrupt replay, delay
  snapshot responses, expire cursors, and expose two authorized test teams.

## Steps

1. Open team A's board and disconnect its stream after a known cursor.
2. Commit task changes during the interruption and allow a resumable reconnect.
3. Disconnect again, expire the cursor, and allow full reconciliation.
4. Delay a team A page response, switch to team B, then release the stale
   response and a stale team A frame.
5. Use browser Back, Forward, and reload on team B's dashboard.

## Expected outcome

- Resumable delivery applies every missing cursor once.
- An expired cursor causes a new boundary and snapshot rather than a partially
  trusted board.
- Every reconciled task appears exactly once in its current canonical column.
- Late team A responses and frames never alter team B cards or counts.
- Back, Forward, and reload reconstruct the same authorized team projection.
